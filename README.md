# MyVoice AI

A voice-first personal AI assistant built with HTML/CSS/JavaScript and a Node.js + Express backend.

## Highlights
- Modern AI dashboard UI with animated assistant orb
- Browser Speech Recognition and Speech Synthesis
- Natural-language command routing
- Google / YouTube / ChatGPT browser actions
- Google search commands
- Quick-action command cards
- Conversation history for the active session
- Live activity feed
- Assistant status states: Ready, Listening, Thinking, Speaking
- Responsive layout for desktop and mobile

## Run locally

### Backend
```bash
cd backend
npm install
# create backend/.env with any backend configuration you use
node server.js
```
Backend runs on `http://127.0.0.1:3000`.

### Frontend
Serve the project folder with a local web server, for example:
```bash
npx serve .
```
Then open the URL shown by the server.
